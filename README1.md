# 📊 Data Visualization with Python

## Project Overview  
This repository contains Project 2 from the *Python for Data Science* course by freeCodeCamp. The focus is on building effective and insightful data visualizations using Python’s most popular libraries. Whether you're analyzing trends, exploring relationships, or presenting findings, this project equips you with the tools to turn raw data into compelling visual stories.

## 🔧 Technologies Used  
- **Python 3.x**  
- **Pandas** – for data manipulation and cleaning  
- **Matplotlib** – for basic plotting and customization  
- **Seaborn** – for advanced statistical visualizations  
- **Jupyter Notebook** – for interactive development and presentation
